# 슈가슈가룬 게임 에셋 스타터팩

## 포함
- backgrounds/: 자체 제작한 16:9 SVG 분위기 배경 6장 (원작 장면 아님)
- items/: 자체 제작한 하트 SVG 3개
- main/: 자체 제작한 메인 배경 SVG 1개
- characters/: 캐릭터 이미지 다운로드 전용 빈 폴더
- docs/source_manifest.json: 온라인에서 확인한 원작 이미지 출처 후보
- docs/download_references.py: 사용자 PC에서 다운로드 시도용 스크립트

**중요:** 이 실행 환경에서 외부 이미지 파일 다운로드가 실패하여 원작 캐릭터/애니 장면은 ZIP에 포함하지 못했습니다. 원작 캐릭터가 들어 있다고 오인하지 마세요. 공식 이미지도 별도 사용 허락 없이 재배포·공개 서비스에 사용할 수 있다고 보장할 수 없습니다.

## GitHub 경로
`src/games/sugarsugarune/assets/` 아래에 `backgrounds`, `characters`, `items`, `main` 폴더를 업로드하세요. 기존 게임 구현 파일은 건드리지 마세요.

## 반복 작업
작품별 이미지 수집은 필요하지만, 공통 하트/이펙트/UI 템플릿은 재사용 가능합니다. 게임마다 전부 새로 만들 필요는 없습니다.
